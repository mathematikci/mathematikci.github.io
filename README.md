# Ayna

iPad ekranını aynı Wi-Fi ağındaki bir tarayıcıda göstermeyi amaçlayan GitHub Pages alıcı arayüzü.

## Önemli teknik sınır

iOS üzerindeki Chrome/Safari, diğer uygulamaların veya tüm sistemin ekranını `getDisplayMedia` ile yakalayamaz. Gerçek canlı yayın için ReplayKit Broadcast Upload Extension içeren yerel bir iPadOS uygulaması gerekir. Bu depo web alıcısının arayüzüdür; gerçek aktarım için ayrıca WebRTC sinyalleşme servisi ve iPad yardımcı uygulaması geliştirilmelidir.

## GitHub Pages
